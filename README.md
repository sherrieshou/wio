
  # Wio

  This is a code bundle for Wio. The original project is available at https://www.figma.com/design/ZX2TqveXZwoAEE1a107YOV/Wio.

  ## Running the code

  Install [pnpm](https://pnpm.io/installation) once (shared store across projects):

  ```bash
  curl -fsSL https://get.pnpm.io/install.sh | sh -
  ```

  Install dependencies and start the dev server:

  ```bash
  pnpm install
  pnpm dev
  ```
